# Contributing to the Health-RI Semantic Interoperability Initiative

!!! warning "Contribution process archived"

    The Health-RI Semantic Interoperability Initiative has been **discontinued**. Its contribution, review, curation, and release workflows are closed. New submissions are not reviewed or integrated into project releases.

    This section is retained as historical documentation of how community contributions were organized during the initiative. See [Initiative Status](../status.md).

During active development, community feedback and contributions were used to improve the quality, coverage, and clarity of the models and ontologies developed as part of the Health-RI Semantic Interoperability Initiative.

The contribution process distinguished between time-bound calls for community review of specific domain models and general contribution channels. These processes are documented in the **[Calls for Community Review](call-for-community-review.md)** and **[Contribution Channels](contribution-channels.md)** pages.

## Historical contribution routes

The initiative used structured GitHub Issue forms for:

- reporting ontology errors;
- requesting new concepts;
- other contributions or collaboration requests; and
- proposing SSSOM mappings.

Those routes are no longer active project intake channels. Existing issues and historical submissions remain part of the repository record.

!!! tip "Archived mapping assistant"

    The **[HRIO Mapping Assistant](https://chatgpt.com/g/g-6990a7e348c4819190ef2de88503ff5e-hrio-mapping-assistant)** was created to help draft candidate mapping rows.

    *If it remains accessible, treat it as an archived, non-maintained drafting aid. There is no active Health-RI curation or publication workflow for its outputs.*
