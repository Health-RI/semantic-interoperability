!!! warning "Final published mapping set — use with care"
    The initiative has been **discontinued**, and this is the final published Health-RI SSSOM Mapping Set. The mapping set contains known inconsistencies, including the unresolved SNOMED sex-related mapping issue [#71](https://github.com/Health-RI/semantic-interoperability/issues/71). No corrective or subsequent mapping release is planned under this initiative. Please assess individual mappings against the documented strategy and evidence before reuse.

!!! note "Scope"
    This page **visualizes** the mappings that were published by the initiative. For the Mapping Set's schema and stable PIDs, see the **[SSSOM Mapping Set](../method/mapping-schema.md)**.

!!! note "Enable the Comment column"
    We recommend enabling the **comment** column so that each entry can be better understood.
